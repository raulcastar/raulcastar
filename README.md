### 🌑 MARE: open-source lunar rover simulator

Procedural lunar terrain, physics-based rovers with stereo, lidar, event and SPAD cameras, pixel-accurate ground truth (including shadows and the rover's own shadow) in Unreal Engine 5, and a ROS 2 GNC stack with web mission control.
